Volleyball ball tracking · runs on your computer

See where the ball goes.

VolleyIQ is a local app for volleyball video. Upload a match clip and it runs a pretrained volleyball detector on about six frames per second, follows the ball with transparent tracking rules, and gives you back an annotated video with an honest per-frame tracking report.

What it does today

VolleyIQ focuses on one thing: finding and following the ball. It is honest about the rest.

In this version

  • Detects the volleyball in each analysed frame
  • Tracks one ball over time, with a status for every frame
  • Annotated video, an interactive results dashboard, and a per-frame CSV
  • Runs entirely on your own computer; videos never leave it

Not yet

  • Player tracking or identification
  • Rally, serve, attack or score detection
  • Tactical statistics
  • A measured, general accuracy figure

How it works

A simple, transparent pipeline. Every step is plain Python you can read.

1

Sample frames

About 6 frames per second are taken from your video, for example every 5th frame at 30 FPS.

2

Detect the ball

A pretrained D-FINE-S volleyball detector looks for the ball in each sampled frame, tile by tile.

3

Track it

Simple rules pick at most one ball per frame, ignore static look-alikes and reject impossible jumps. Nothing is guessed in between.

4

Review

Watch the annotated video, step through each frame's status on a timeline, and download the video and CSV.

Honest results, frame by frame

Instead of a single confidence number, every analysed frame gets a status from explicit rules. A high model score alone never makes a frame "good".

Tracking statuses

Private by design

The app listens only on your own computer. Uploaded videos are deleted after analysis and results after 24 hours.

Interactive dashboard

A clickable, keyboard-friendly timeline jumps the video to any analysed frame and shows why it got its status.

One-click start

On Windows, double-click VolleyIQ.vbs; the app opens in your browser without a console window.

Get started

VolleyIQ is a local Python app, not an online service: this page only describes it. You run it on your own Windows computer, ideally with an NVIDIA GPU.

  1. Get the code

    Clone the repository from GitHub.

    git clone https://github.com/jj-codes7/VolleyIQ.git
cd VolleyIQ

  2. Create the Python environment

    Python 3.10. The requirements pull the CUDA build of PyTorch.

    py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

  3. Download the model once, then launch

    Follow the README's "Detect the ball automatically" section once to download the 41 MB model, then double-click VolleyIQ.vbs (or VolleyIQ.bat).
